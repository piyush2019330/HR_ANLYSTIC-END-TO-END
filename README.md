This is an end-to-end HR Analytics project where data is analyzed using Python, SQL, Machine Learning, and Power BI to generate insights about employee behavior and attrition.

The project covers the full data pipeline:

Data Cleaning
Exploratory Data Analysis (EDA)
Feature Engineering
SQL Analysis
Machine Learning Modeling
Data Visualization (Power BI)
🎯 Objectives
Understand employee attrition patterns
Identify key factors affecting retention
Build predictive models for attrition
Create interactive dashboards for decision-making
🛠️ Tech Stack
Python (Pandas, NumPy, Matplotlib)
Machine Learning (Scikit-learn)
MySQL (Data Analysis)
Power BI (Dashboard & Visualization)
Git & GitHub
